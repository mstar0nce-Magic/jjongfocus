# 쫑글킵 v0.2.0

Google Keep은 빠르게 수집하고, 쫑글킵은 정리해서 행동으로 바꾸는 역할에 집중한 심플 PWA입니다.

## 사용 흐름
1. 캡처·사진·메모는 Google Keep에 빠르게 저장
2. Keep에서 공유 → 쫑글킵
3. 쫑글킵에서 `할 일 / 아이디어 / 자료`로 분류
4. 필요한 항목만 `오늘`로 보내기
5. 끝난 자료는 보관

## 핵심 기능
- Android 설치형 PWA의 Web Share Target 지원
- 이미지·텍스트·링크 공유 수신
- 직접 메모 및 사진 저장
- 저장 후 내용·사진·분류·오늘 여부 수정
- 받은 것 / 오늘 / 보관 보기
- 검색
- IndexedDB 로컬 저장
- 오프라인 앱 셸

기존 쫑포커스/타임라인/일기 모듈은 제거하고 쫑글킵 단일 목적 앱으로 정리했습니다.
