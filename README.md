# 쫑글킵 v0.1.0

Google Keep처럼 빠르게 사진, 메모, 체크리스트를 저장하되 사용자의 실제 흐름에 맞춰 `오늘`, `지금 하나`, `다시 돌아오기` 기능을 더한 개인 메모 PWA입니다.

## 핵심 원칙
- 저장은 빠르게.
- 분류는 나중에.
- 오늘 할 일과 지금 하나는 최소화.
- 머리가 복잡하거나 멈췄을 때는 `다시 돌아오기`로 재진입.

## 현재 구현
- 일반 메모
- 사진 1장 첨부
- 체크리스트
- 검색
- 상단 고정
- 색상 순환
- 라벨
- 오늘 표시
- 지금 하나 1개
- 보관함
- `🌿 다시 돌아오기`
- 모바일/PC 반응형
- IndexedDB 저장
- PWA 오프라인 캐시

## 배포
기존과 동일하게 GitHub `main` 브랜치에 반영하면 연결된 Cloudflare Pages가 자동 배포합니다.
